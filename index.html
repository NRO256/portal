ご利用案内と安全性について

ダウンロードから日常利用・削除まで、すべてのソフトで共通してご確認いただきたい事項です。

導入・更新・削除の方法

  • 各カードの「ダウンロード」から GitHub Releases を開き、Assets 欄の ZIP ファイルをダウンロードして任意のフォルダへ展開してください。
  • 更新時は新しい ZIP の実行ファイルで上書きするだけです。設定ファイルを引き継げます。
  • アンインストール時は展開したフォルダごと削除するだけで完了し、Windows レジストリにゴミを残しません。

Windows SmartScreen 警告について

  • 個人開発のオープンソースソフトのため商用コード署名は付属していません。初回起動時に「WindowsによってPCが保護されました」という青い画面が表示される場合があります。
  • この場合は画面内の「詳細情報」をクリックし、内容をご確認のうえで「実行」を選択して起動してください。
  • すべての公開ソフトは GitHub 上でソースコードを公開しており、ビルド構成も透明化しています。

ライセンス・動作条件・免責

  • 掲載ソフトはいずれも MIT License のフリーウェア・オープンソースソフトウェアとして公開しています。
  • 対応 OS や管理者権限（UAC 昇格）の要否はソフトごとに異なりますので、各カードの仕様欄をご確認のうえご利用ください。
  • 無保証（AS IS）で提供されます。システム操作系ツールのご利用前には必要に応じてバックアップをおすすめします。
